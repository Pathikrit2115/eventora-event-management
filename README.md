
# Eventora - Event Management Website

## Project Overview

Eventora is a modern, responsive event management and discovery website developed as part of the K Explore Web Designing assignment.

It allows users to explore upcoming events, search for specific events, filter events by category, view event details and register for their preferred events.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Git and GitHub
- Netlify

## Features

- Responsive navigation bar
- Modern hero section
- Dynamic event cards
- Event search functionality
- Category-based event filtering
- Event details popup
- Registration form
- JavaScript form validation
- Registration confirmation message
- Local Storage registration management
- Dark and light mode
- Responsive mobile and desktop layouts

## How to Run Locally

1. Clone this repository.
2. Open the project folder in VS Code.
3. Install the Live Server extension.
4. Right-click index.html.
5. Select Open with Live Server.

## Registration Management

Registration information is stored in browser Local Storage using JavaScript.

This is a frontend demonstration project and does not use a centralized database or backend.
